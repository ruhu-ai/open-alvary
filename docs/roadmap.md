# Roadmap

## v0.1 — catalogue and enforced boundaries (implemented)

Canonical contracts, initial relational migration, fail-closed rights gates,
Nigeria catalogue, modular parser skeleton, small read-only API, public UI,
versioned sample exports and deterministic tests. Four metadata entries; no
rights-cleared Nigerian text. This is a local foundation, not a public launch.

## Next — reviewed content and operations

Appoint reviewers; settle software/data contribution terms and metadata licensing;
verify actual source licences, privacy, database rights and attribution; verify
consolidations and historical law. Add a controlled review UI with append-only
rights history, versioned content review records and audited release approvals.
Integrate a concrete OCR provider, legal-structure adapters and page-level anchors.
Keep immutable raw manifestations outside public distribution until cleared.

## Africa-wide expansion

Nigeria is the first pilot for a broader African public legal infrastructure project.
Select further jurisdictions through a published assessment of authoritative sources,
source-specific permissions, legal structures, document formats, languages and reviewer
capacity. Publish explicit coverage gaps. Test reusable adapters and selected-language
benchmarks before claiming real legal-content coverage; synthetic fixtures are not law.
The proposed funding programme is staged around measured costs and useful outcomes,
with no guarantee of comprehensive continental coverage or a funding award.

## Then — broader jurisdictions and reliable scale

Add authority hierarchies, languages/translations, reviewed amendment links,
source freshness monitoring and coverage gaps. Add bounded SQL queries,
PostgreSQL text indexes, streaming releases, signed manifests and operational
withdrawal notices. Complete production deployment, backups and monitoring.

## Optional — machine access and hosted services

Add read-only MCP tools and replaceable embeddings without making either a
prerequisite for structured data. Evaluate hosted free/paid service tiers while
keeping public corpus access and data rights separate from Alvary's commercial AI.
