# Source inclusion

Start with official governments, legislatures, courts, regulators and gazettes.
Add jurisdiction-neutral catalogue records with stable IDs, issuing authority,
language, citation, canonical URL and URL type. A landing page is not a text version.
Record unknown currentness honestly. Never imply comprehensive coverage.

Acquisition requires an operator's review of the source terms, allowed fetching,
privacy and retention. Network adapters require exact HTTPS document allowlists,
do not follow redirects and enforce a 25 MiB limit. Run acquisition with restricted
egress and resource limits; this is not an arbitrary public URL-fetching service.

Do not acquire commercial databases, Kenya Law or other third-party compilations
without explicit source-specific review. No commercial/private records belong in
this public Git repository. Unapproved working text may only enter a lawful,
operator-controlled staging database, never tracked files or public exports.
